# Flyer Calendar Scanner

## Project Goal
A time-management tool that automates repetitive tasks involved in organizing a student's schedule and keeping track of events and deadlines.

## MVP
The MVP allows users to scan event flyers, extract relevant event information using the Gemini API, review the extracted details, and automatically add events to Google Calendar.

## Future Plans
- Scrape Purdue and company websites for events and opportunities.
- Extract important events and deadlines from emails.
- Set reminders for upcoming events.

## Tech Stack
- **Language:** Python
- **Libraries:** Google Calendar API client, Google OAuth library
- **External APIs:** Gemini API, Google Calendar API
- **Data Storage:** JSON
- **Tools:** VS Code, Git/GitHub
